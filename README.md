# Optimistic Orator - GenLayer Mini Game

A multiplayer AI-powered debate game built on **GenLayer** that showcases **Intelligent Contracts** and **Optimistic Democracy**.

![Game Banner](https://via.placeholder.com/800x300?text=Optimistic+Orator)

## 🎮 Game Overview

**Optimistic Orator** is a fast-paced, fun debate mini-game where players craft arguments, get evaluated by AI validators, and earn XP through consensus.

The game demonstrates GenLayer’s core strengths:
- LLM-powered **Intelligent Contracts**
- Natural language understanding on-chain
- AI validator consensus (Optimistic Democracy)

## ✨ Key Features

- Real-time multiplayer debate rooms (4-8 players)
- AI judges evaluate arguments on Clarity, Coherence, Persuasiveness, and Evidence
- XP rewards based on argument quality and consensus
- Appeal mechanism for disputed results
- Weekly leaderboard with seasonal rewards
- Beautiful Classical Modernism UI design
